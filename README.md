# Six Sigma Study Lab

Interactive Lean Six Sigma White Belt study website.

## Site
- White Belt lessons and vocabulary
- Flashcards and quizzes
- DMAIC simulator
- Standard Work & Checklists mini-game
- Retro arcade features
- Progress, XP, notes, and rewards stored locally in the visitor's browser
- Optional support/tip section (payment link intentionally disabled until configured)

## Security
The Vercel configuration applies hardened browser security headers. Payment credentials are never collected or stored by this site.

## Deployment
This repository is the source of truth for the public website. Import it into Vercel; no build command is required.
