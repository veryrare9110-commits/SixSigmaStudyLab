Practice standard work by moving across a process board and checking the correct step at each station. You can also launch it from the RETRO WHITE BELT ARCADE. This board now uses the same retro pixel styling.

A reference manual documents how a process should be done. A checklist is a short tool you can use while doing the work so important steps are not skipped.

Reference manual→ Standard steps→ Checklist→ More consistent work
Learn it

Reference manual vs. checklist

1
Reference manual

The detailed instructions: what to do, how to do it, standards/specifications, safety notes, and what to do when something goes wrong.

2
Checklist

The short reminder you use during the process to confirm critical steps were completed.

3
Standard work

The agreed best-known method for doing the work consistently.

White Belt connection:

Documented steps reduce reliance on memory, help prevent skipped steps, and can reduce unwanted variation and defects.
